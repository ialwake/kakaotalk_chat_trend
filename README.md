# 카톡 대화 추이

Mac 카카오톡에서 내보낸 1:1 대화 CSV를 넣으면, 두 사람의 대화가 시간에 따라 어떻게 변해 왔는지 보여 주는 웹 페이지입니다.

- 총 메시지 수, 대화한 날, 대화한 날 평균 메시지 수
- 두 사람의 메시지 비율
- 월별·주별 대화 추이 차트
- 최고의 달, 최장 연속 대화, 최장 공백기
- 요일 × 시간대 히트맵 (언제 대화하는지)

## 사용법

### 바로 쓰기

<https://ialwake.github.io/kakaotalk_chat_trend/> 에서 CSV 파일을 끌어다 놓으면 됩니다.
파일이 없으면 "샘플 데이터로 먼저 보기"로 화면을 먼저 볼 수 있습니다.

### 내려받아 쓰기

1. 이 저장소 페이지에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다.

설치나 인터넷 연결이 필요 없습니다.

### CSV 내보내기

Mac 카카오톡에서 1:1 채팅방을 열고, 채팅방 메뉴에서 **대화 내보내기**를 선택하면 `.csv` 파일이 저장됩니다.

## 지원 범위

- **Mac 카카오톡(한국어 설정)에서 내보낸 CSV만** 읽습니다.
- Windows PC·모바일 카카오톡의 `.txt` 내보내기와 영어 설정으로 내보낸 파일은 지원하지 않습니다.
- 1:1 대화를 기준으로 만들었습니다. 단체방 파일을 넣으면 메시지가 많은 두 사람을 비교하고 나머지는 "기타"로 묶습니다.

## 개인정보

- 대화 파일은 브라우저 안에서만 읽고, 어디에도 보내지 않습니다.
- 외부 요청(CDN 스크립트·웹 폰트·분석 도구)이 없습니다.
- 위의 GitHub Pages 링크로 열어도 GitHub에서 받는 것은 페이지 파일(HTML·CSS·JS)뿐입니다. 대화 파일은 브라우저 밖으로 나가지 않습니다.

## 개발

런타임 의존성은 없고, 검사 도구(ESLint)만 개발 의존성으로 씁니다. Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run check   # lint → build → test
```

브라우저에서 확인할 때는 로컬 서버로 띄워도 됩니다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1   # http://127.0.0.1:8765/
```
